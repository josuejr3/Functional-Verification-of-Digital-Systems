# Verificação Funcional de Sistemas Digitais

Repositório da disciplina **Verificação Funcional de Sistemas Digitais**, contendo materiais, códigos-fonte, testbenches, modelos de referência, exercícios e projetos desenvolvidos ao longo da disciplina.

---

## 📚 Objetivos da Disciplina

A disciplina tem como foco o estudo de técnicas de verificação utilizadas no desenvolvimento de sistemas digitais, abordando:

- Conceitos de verificação funcional
- Desenvolvimento de testbenches
- Modelagem em SystemVerilog
- Criação de modelos de referência
- Verificação baseada em simulação
- Geração de estímulos
- Cobertura funcional
- Debug e análise de resultados
- Metodologias de validação de hardware

---

## 🛠️ Tecnologias e Ferramentas

As principais ferramentas e linguagens utilizadas neste repositório são:

- **SystemVerilog**
- **Verilog**
- Simuladores HDL
  - ModelSim / QuestaSim
  - Vivado Simulator
  - Icarus Verilog
- Git e GitHub
